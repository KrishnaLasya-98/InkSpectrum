# Video Storyboard: EVS Class 1 — Lesson 8: Animal Life

**Source:** `RPS - EVS - CLASS 1 - INDIVIDUAL - B (2026) PRINTFILE-pages-2.pdf`
**Target Audience:** Grade 1 students (6–7 years old)
**Duration:** ~8–10 minutes
**Style:** Bright, colorful, animated educational video with warm narration

---

## Visual Style Guide

| Element | Specification |
|---------|---------------|
| **Color Palette** | Primary: #4CAF50 (green), #2196F3 (blue), #FF9800 (orange); Backgrounds: soft pastels (#E8F5E9, #E3F2FD) |
| **Typography** | Titles: Comic Sans MS / Nunito ExtraBold, 48–64px; Body: Nunito Regular, 28–32px; Keywords: bold, colored |
| **Character Style** | Simple, rounded, friendly cartoon animals with large eyes (preschool-friendly) |
| **Animation Style** | Smooth 2D motion, 24fps, gentle bounce effects, no rapid cuts |
| **Transitions** | Fade (0.5s), slide (0.3s), zoom-in for emphasis |
| **Music** | Light, upbeat instrumental background (volume 20%), SFX for animal sounds |
| **Narration Tone** | Warm, enthusiastic, slightly slower pace (0.9× speed) |

## Motion Graphics & Animation Specifications

### Particle Effects

| Effect | Usage | Implementation |
|--------|-------|---------------|
| **Bubbles** | Underwater scenes | Rising circles with opacity fade |
| **Hearts** | Life Skills section | Floating heart shapes, pink/red |
| **Stars** | Correct answers | Burst from center, 5-point stars |
| **Leaves** | Forest scenes | Falling leaf sprites |
| **Clouds** | Sky/bird scenes | Slow horizontal drift |

### Text Animations

| Animation | Trigger | Duration | Easing |
|-----------|---------|----------|--------|
| **Fade In** | Scene start | 0.5s | Ease-in |
| **Slide Up** | Bullet points | 0.3s each | Ease-out |
| **Pop In** | Key vocabulary | 0.2s | Bounce |
| **Typewriter** | Questions | 0.05s per char | Linear |
| **Zoom In** | Title cards | 0.4s | Elastic |

### Transitions

| From | To | Effect | Duration |
|------|----|--------|----------|
| Scene N | Scene N+1 | Fade through black | 0.5s |
| Within scene (sub-topic) | — | Slide left/right | 0.3s |
| Exercise → Answer | — | Zoom + flash | 0.4s |
| Activity → Closing | — | Curtain wipe | 0.6s |

```
Week 1: Asset Creation
  ├── Design all backgrounds (8 scenes)
  ├── Create animal sprites (15+ characters)

  ├── Animate Scene 1–7
  ├── Animate Scene 8–13
  ├── Add transitions and effects
```
