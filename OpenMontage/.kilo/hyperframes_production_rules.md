# EVS Lesson 8 HyperFrames Production Rules

These rules are repository policy for every future EVS Lesson 8 build.

- Use HyperFrames only for final composition. Do not silently substitute another compositor.
- The approved visual baseline is `projects/evs-lesson-8/one-minute-preview/hyperframes/renders/evs-one-minute-clean-final.mp4` and its source composition. Shared UI primitives in the full project must remain visually identical: Arial family, baseline font sizes, colors, panels, radii, shadows, positions, easing, 1920x1080, and 30fps.
- Read `projects/evs-lesson-8/artifacts/source_text_manifest.json` as authoritative. Extract every title, subtitle, heading, body line, recall line, glossary line, assessment prompt, activity, and Life Skills line dynamically from the source manifest. Do not rely silently on generated educational-plan or script paraphrases. Preserve source wording and punctuation. Narration bridge words are audio-only.
- At the beginning of every section, show that section's source-derived title and subtitle prominently centered in a graphics-only HyperFrames title card. Never put image or video behind a title card.
- Use actual narration audio, word-level ASR, progressive word-by-word captions, phrase-level visual selection, and then HyperFrames rendering. Future words stay hidden; the current word is highlighted; phrase/card visibility is cleared during gaps and punctuation pauses.
- Inspect media by observed frames and subjects, not filenames. Match Water Animals to fish/aquatic motion, Birds to birds, Insects to insects, Animal Homes to recognizable nest/burrow/den/kennel/shed/stable, and animal names to the named subjects. Prefer semantically correct existing ModelLabs motion. Use staged animated stock only for confirmed matches. Use a graphics-only fallback when no suitable motion exists. Record asset source, observed subject, purpose, and source phrase. Report every mismatch and candidate query/path.
- Keep one active topic card and one active subtitle phrase. Hard-clear old cards before each next topic. Schedules follow actual audio, word, sentence, punctuation, transition, and explicit interactive hold timing. Never use generic 30-second section windows.
- Preserve the approved architecture: motion clip, separate source-content/highlight card, and separate word captions. Recall, Glossary, Assessment, Activity, and Life Skills may add panels only when they use the same baseline primitives.
- Assessment sections are I Answer, II Fill in the blanks, and III Choose the correct answer. Show one question at a time, keep the question layer separate from subtitles, use a 5-second prediction pause and 4-second reveal, and hard-clear before the next question. If no verified answer key exists, show exactly `Guess and move to the next question.`
- Include Activity and the exact Life Skills slogan: `Animals also have feelings.` / `Do not hurt animals.` / `They will be friendly to us.` / `Protect animals.`
- Every build must emit an auditable coverage report containing exact source lines covered/uncovered, assessment IDs, titles, image references, rendered transcript word count when available, and required manual frame checks. Run focused tests, Python compile, generated-plan validation, HyperFrames check, and short representative boundary previews. Do not call paid ModelLabs APIs or run the full long render during correction work.
