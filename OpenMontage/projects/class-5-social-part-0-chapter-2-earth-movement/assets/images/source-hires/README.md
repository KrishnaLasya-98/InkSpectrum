# Chapter 2 textbook figure crops

These PNGs are direct Poppler renders of the original split chapter PDF,
`textbook-collections/class-5-social/source-chapters/chapter-02-earth-movement.pdf`,
at 300 DPI. They are not generated or retouched artwork.

- `axis-tilt.png`: PDF page 2, crop x=290, y=1020, width=520, height=470.
  Preserves the original 23.45-degree figure label, axis, equator and orbital
  plane labels. The paragraph separately prints 23.5 degrees.
- `rotation-revolution.png`: PDF page 2, crop x=1690, y=2270, width=700,
  height=760. Preserves the original comparison labels and four season icons.
- `solstice-equinox.png`: PDF page 4, crop x=340, y=540, width=2000,
  height=1120. This crop includes the source watermark and has very tight
  bottom clearance; prefer the original extracted `imageFile9.png` for the
  final full diagram unless a wider, source-faithful crop is reviewed.

Do not rewrite figure dates to match the prose: the figure uses date ranges
while the paragraph names specific days. Both should appear in their original
contexts. At final size, check every label in a rendered frame, not only the
PNG on disk.
