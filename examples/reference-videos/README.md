# Educational video reference examples

These archives contain the approved rendered-video references used to evaluate
OpenMontage educational output across English, EVS, and Mathematics.

The ZIP files are stored with Git LFS because rendered MP4 files exceed
GitHub's normal per-file limit. After cloning, install Git LFS and run:

```bash
git lfs install
git lfs pull
```

Extract each archive to obtain the corresponding MP4:

- `english-class1-at-the-beach-final-v7.zip`
- `evs-lesson-8-3d-synced-final.zip`
- `maths-class1-two-digit-numbers-final-v4.zip`

Generated project workspaces, textbook PDFs, credentials, browser profiles,
personal agent histories, and provider caches are intentionally excluded from
the public repository.
